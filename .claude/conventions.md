# 项目规范

本模板不预置运行时代码框架。这里仅保留通用约定，具体项目可以在立项后补充自己的编码规范。

## 通用编码

- 公共类型、属性、方法使用 PascalCase。
- 私有字段使用 `_camelCase`。
- 优先写清晰直接的实现，再考虑抽象。
- 只在能减少真实复杂度时引入框架或公共层。
- 异步、输入、资源、事件、配置表方案按项目实际技术选型决定。

## Unity

- `Update` 中避免 GC alloc。
- Editor 代码放在 `Editor/` 目录或 Editor-only asmdef。
- 运行时代码和 Editor 工具代码分离。
- ScriptableObject 用作配置资产，不作为运行时数据库。
- 新增代码前先观察当前 `Assets/` 下真实目录结构，不假设 `Assets/Scripts` 已存在。

## 文档

- 新项目确立程序架构后，可在本文件追加项目专属约定。
- 不要把临时业务示例写成模板级强制规范。
