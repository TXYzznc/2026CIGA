# 六边形重力连锁玩法｜程序开发需求文档

> 用途：供 Game Jam 程序开发、联调和策划配置使用。  
> 当前文档锁定已经确认的玩法底层。棋子具体得分公式、新棋子及无尽模式数值将在后续设计中补充，程序层需要预留配置接口，不能写死。

---

## 1. 项目概述

玩家旋转六边形棋盘，改变棋子相对重力方向，再按下“拍击”，使棋子沿屏幕下方移动。

移动棋子撞到其他棋子后，只触发被撞棋子的能力。能力可能继续推动、分裂、生成或移除棋子，形成连锁。

每轮拥有固定拍击次数。次数耗尽后检查本轮目标分：

```text
当前分数 ≥ 本轮目标分：通过
当前分数 < 本轮目标分：失败
```

通过后扣除目标分，剩余分数继承至下一轮；失败后从当前关卡第1轮重新开始。完成三关后进入无尽模式。

---

## 2. 术语

```text
关卡 Level
└── 轮次 Round
    └── 拍击回合 Smack Turn
```

- **关卡 Level**：由多个连续轮次组成。
- **轮次 Round**：包含固定数量的拍击回合，结束后结算目标分。
- **拍击回合 Smack Turn**：玩家旋转棋盘并按下一次拍击，直到事件完全结算。
- **重力方向**：始终朝屏幕下方。
- **棋盘方向**：棋盘当前相对屏幕的旋转状态。
- **稳定状态**：事件队列为空，且没有事件动画正在播放。
- **最长一排 MaxRowLength**：沿六边形棋盘三个标准轴向之一，连续经过的最大格子数。

## 3. Game Jam 内容范围

| 关卡 | 轮次数 | 最长一排 | 初始棋子数 | 每轮拍击数 |
|---|---:|---:|---:|---:|
| 第1关 | 4 | 6 | 5 | 7 |
| 第2关 | 5 | 8 | 10 | 7 |
| 第3关 | 7 | 10 | 15 | 7 |

- 单轮目标时长：1～2分钟。
- 所有数值必须可配置。
- 第3关完成后进入无尽模式。
- 无尽模式具体成长公式后续补充，当前先实现入口与循环能力。

## 4. 总流程

### 4.1 关卡流程

```text
进入关卡
→ 创建棋盘
→ 生成初始棋子
→ 进入第1轮
→ 完成7次拍击
→ 轮次结算
├─ 失败：重新初始化当前关卡
└─ 成功：
   → 扣除本轮目标分
   → 若还有下一轮：新增墙体 → 连续两次三选一 → 下一轮
   → 若为最后一轮：进入下一关
```

### 4.2 拍击回合流程

```text
自由旋转棋盘
→ 按下拍击
→ 消耗1次拍击次数
→ 生成重力事件
→ FIFO事件队列结算
→ 队列为空且动画结束
→ 棋盘稳定
→ 若不是本轮第7次拍击：三选一
→ 返回旋转阶段
```

第7次拍击结束后不出现普通三选一，直接进行轮次结算。

## 5. 关卡与轮次规则

### 5.1 同一关卡内继承

轮次之间继承：

- 棋盘模板；
- 棋子及其位置；
- 墙体；
- 当前剩余分数。

每轮拍击次数重新设置为配置值，当前暂定7次。

### 5.2 轮次通过

```text
RemainingScore = CurrentScore - TargetScore
```

当 `CurrentScore >= TargetScore` 时：

1. 当前分数扣除目标分；
2. 剩余分数继承；
3. 按配置随机生成新增墙体；
4. 连续进行两次三选一；
5. 进入下一轮。

### 5.3 轮次失败

当 `CurrentScore < TargetScore` 时：

- 当前关卡失败；
- 回到当前关卡第1轮；
- 棋盘、棋子、墙体和分数全部重新初始化。

例如第2关第4轮失败，重新开始第2关第1轮。

### 5.4 关卡切换

关卡之间不继承：

- 棋盘；
- 棋子；
- 墙体；
- 分数。

## 6. 玩家操作

### 6.1 旋转

- 玩家旋转棋盘，重力方向始终朝屏幕下方。
- 棋盘以60°为基本单位。
- 支持顺时针、逆时针调整。
- 支持60°、120°、180°旋转。
- 拍击前可以反复调整，不消耗次数。
- 旋转过程中棋子不移动。

### 6.2 拍击

按下拍击后：

1. 锁定当前棋盘方向；
2. 消耗1次拍击次数；
3. 重置本次拍击的连击计数；
4. 禁止旋转和再次拍击；
5. 生成初始重力移动事件；
6. 进入结算状态。

拍击不可撤销。

---

## 7. 棋盘系统

### 7.1 坐标

建议使用六边形轴坐标：

```text
(q, r)
```

六个邻接方向定义为：

```text
D0、D1、D2、D3、D4、D5
```

按顺时针排序。

### 7.2 棋盘模板

棋盘使用模板配置，而不是根据公式临时生成。每个模板至少包含：

- `BoardTemplateID`
- 合法格子坐标列表
- `MaxRowLength`
- 棋盘中心
- 可生成棋子格集合
- 可生成墙体格集合

当前需要三种模板：

- 最长一排6格；
- 最长一排8格；
- 最长一排10格。

### 7.3 格子占用

每个格子只允许一种状态：

- 空格；
- 棋子；
- 墙体。

棋子和墙体均占1格。

---

## 8. 重力移动

### 8.1 基础规则

- 只有拍击会触发全棋盘重力。
- 棋子沿当前重力方向移动到最远合法格。
- 普通重力不会让棋子掉出棋盘。
- 棋子会停在：
  - 其他棋子前；
  - 墙体前；
  - 棋盘最边缘格。

### 8.2 重力轨道顺序

1. 根据当前重力方向将棋盘划分为平行轨道；
2. 轨道按屏幕位置从左到右排序；
3. 每条轨道内部从下到上排序；
4. 下方棋子的移动事件先入队。

### 8.3 实时状态

事件不预存最终落点。

移动事件执行时读取：

- 棋子是否仍存在；
- 棋子实时位置；
- 当前棋盘占用；
- 当前移动方向。

如果对象已被删除，该事件失效并跳过。

### 8.4 悬空

爆炸、分裂等能力造成的空位不会立即触发全局重力。

能力结算后产生的悬空棋子保持原位，等下一次拍击再下落。

---

## 9. 碰撞规则

棋子A撞击棋子B，必须满足：

1. A本次实际移动至少1格；
2. A停止后，移动方向正前方相邻格存在B；
3. B是棋子，不是墙体。

只判定正前方棋子。

以下情况不产生碰撞：

- A没有位移；
- A撞墙；
- A撞棋盘边缘；
- 推动失败；
- 棋子被直接生成到相邻位置；
- 棋子被推出棋盘。

发生碰撞时，只触发被撞棋子B的能力。

---

## 10. 统一事件队列

### 10.1 原则

所有逻辑事件进入同一个FIFO队列：

```text
先入队 → 先执行
```

事件执行过程中产生的新事件加入队尾，不插队。

### 10.2 事件类型

首版建议包含：

| 事件类型 | 说明 |
|---|---|
| GravityMove | 拍击产生的重力移动 |
| PushMove | 爆炸或分裂产生的推动 |
| Collision | 移动结束后的碰撞 |
| AbilityTrigger | 执行被撞棋子的能力 |
| Explosion | 爆炸效果 |
| Split | 分裂效果 |
| Spawn | 生成棋子 |
| Remove | 删除棋子 |
| Score | 增加分数 |

### 10.3 结束条件

本次拍击同时满足以下条件后结束：

- 事件队列为空；
- 当前没有事件动画正在播放。

不要求全部棋子贴底。

### 10.4 安全保护

默认配置：

- 单次拍击最多执行500个事件；
- 单个棋子单次拍击最多触发能力50次。

达到限制后：

1. 停止生成新事件；
2. 清空剩余队列；
3. 保留当前棋盘；
4. 保留已经获得的分数；
5. 记录异常日志；
6. 结束本次拍击。

## 11. 当前棋子能力

> 棋子具体得分方式后续设计。所有能力必须通过统一接口返回得分事件，禁止在底层移动逻辑中写死分数。

### 11.1 普通棋

- 无特殊能力；
- 可移动、可被推动、可被推出棋盘；
- 被撞后不产生能力事件。

### 11.2 得分棋

- 被撞时触发得分能力；
- 触发后保留；
- 具体得分公式由棋子配置决定。

### 11.3 爆炸棋

被撞后：

1. 爆炸棋保留；
2. 从当前重力方向开始，按顺时针处理六个相邻方向；
3. 每个方向只处理紧邻棋子；
4. 将目标沿远离爆炸中心方向推动1格。

推动结果：

- 目标格为空：移动并进行碰撞判定；
- 目标格有棋子或墙：不移动、不碰撞；
- 目标格在棋盘外：棋子飞出并删除；
- 被推出棋盘不触发能力。

### 11.4 分裂棋

被撞后：

1. 原棋子删除；
2. 根据撞击方向，向左右偏转60°的两个方向分别生成一枚分裂棋；
3. 两次生成独立进入事件队列；
4. 先处理顺时针偏转方向，再处理另一方向。

生成目标被占用时：

1. 优先沿生成方向推动整条棋子链；
2. 从最远端开始移动；
3. 实际移动的棋子进行碰撞判定；
4. 分裂挤压不能将棋子推出棋盘；
5. 推动失败则寻找最近合法空格；
6. 最近空格同距离时，从原生成方向开始顺时针选择；
7. 无空格则该次生成失败。

直接生成不产生碰撞。

## 12. 墙体系统

- 墙体不可移动；
- 不受重力；
- 不受爆炸推动；
- 不受分裂挤压；
- 不触发能力；
- 不参与碰撞；
- 棋子撞墙后停止，不产生碰撞。

### 12.1 轮间新增墙体

轮次通过后，按照下一轮配置新增墙体：

- 生成位置从允许墙体的棋盘格中随机选择；
- 墙体可以生成在空格；
- 墙体也可以替换棋子；
- 被替换棋子直接删除；
- 删除不触发能力、得分或离场事件；
- 同一个格子不可重复生成墙体。

---

## 13. 三选一系统

### 13.1 普通三选一

- 本轮前6次拍击完成后各触发一次；
- 第7次拍击后不触发；
- 从当前选择池中抽取3个不同棋子；
- 玩家选择1个或跳过；
- 选中的棋子随机放入合法空格；
- 生成后不立即下落、不触发碰撞。

若没有合法空格：

- 本次棋子直接丢弃；
- 不替换已有棋子；
- 不提供补偿。

### 13.2 轮间奖励

轮次通过后、下一轮开始前：

```text
新增墙体
→ 连续三选一
→ 连续三选一
→ 下一轮开始
```

轮间两次选择沿用普通三选一界面和规则，并允许跳过。

## 14. 状态机

```text
Boot
→ LevelInit
→ RoundInit
→ RotationPreview
→ SmackConfirm
→ GenerateGravityEvents
→ ResolvingEvents
→ RoundStable
├─ 本轮仍有拍击次数 → PieceChoice → RotationPreview
└─ 拍击次数耗尽 → RoundJudge
   ├─ 失败 → LevelFail → LevelInit
   └─ 成功
      ├─ 还有下一轮 → AddWalls → BonusChoice ×2 → RoundInit
      └─ 关卡完成 → LevelSuccess → NextLevel / EndlessMode
```

## 16. 核心伪代码

### 16.1 拍击

```text
OnSmack():
    if State != RotationPreview:
        return

    State = ResolvingEvents
    RemainingSmackCount -= 1
    ComboCount = 0
    ExecutedEventCount = 0
    ResetPieceTriggerCounts()

    tracks = BuildGravityTracks(CurrentGravityDirection)
    tracks.Sort(LeftToRight)

    for track in tracks:
        pieces = track.GetPieces()
        pieces.Sort(BottomToTop)

        for piece in pieces:
            EventQueue.Enqueue(
                GravityMove(piece.ID, CurrentGravityDirection)
            )

    ProcessEventQueue()
```

### 16.2 队列

```text
ProcessEventQueue():
    while EventQueue not empty:
        if ExecutedEventCount >= EventLimit:
            EventQueue.Clear()
            LogOverflow()
            break

        event = EventQueue.Dequeue()

        if event.TargetInvalid():
            continue

        Execute(event)
        ExecutedEventCount += 1

    WaitUntilAnimationsFinished()
    OnSmackStable()
```

### 16.3 拍击结束

```text
OnSmackStable():
    if RemainingSmackCount > 0:
        OpenNormalChoice()
    else:
        JudgeRound()
```

### 16.4 轮次结算

```text
JudgeRound():
    if CurrentScore < Round.TargetScore:
        RestartCurrentLevel()
        return

    CurrentScore -= Round.TargetScore

    if Round.IsFinalRound:
        EnterNextLevelOrEndless()
        return

    AddRandomWalls(NextRound.EnterAddWallCount)
    OpenBonusChoice()
    OpenBonusChoice()
    StartNextRound()
```
