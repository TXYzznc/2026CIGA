# 六边形重力连锁玩法｜棋子美术需求文档

> 用途：供 Game Jam 美术制作10种棋子及其低成本能力表现。  
> 目标：在六边形小格内一眼区分棋子类型，动画尽量依靠程序位移、缩放、旋转和替换贴图完成。

---

## 1. 整体风格

### 1.1 风格关键词

- 手工拼贴；
- 剪纸；
- 复印机颗粒；
- 粗手绘线；
- 错位印刷；
- 高对比色块；
- 旧纸张；
- 实验漫画；
- 低帧定格动画。

画面应像使用纸张、剪刀、胶带和马克笔快速制作出来。

### 1.2 建议色板

| 颜色 | 用途 |
|---|---|
| 荧光黄 | 棋子主体、高亮 |
| 深蓝 | 轮廓、能力符号 |
| 米白 | 纸张底色、局部留白 |
| 深紫或黑 | 危险、吞噬、阴影 |

每枚棋子尽量只使用2～3种主色。

### 1.3 棋子统一结构

每枚棋子由以下内容组成：

1. 一张不规则纸片主体；
2. 一圈粗轮廓；
3. 一个清楚的中央能力符号；
4. 少量纸张颗粒；
5. 可选的局部撕边或错位色块。

优先通过**轮廓和中央符号**区分棋子，不依赖文字。

---

## 2. 制作规格

### 2.1 图片

- PNG透明背景；
- 每枚棋子统一使用512×512画布；
- 主体尽量占画布70%～85%；
- 棋子缩小到六边形格内时仍能识别；
- 不绘制复杂背景。

### 2.2 动画

每枚棋子默认只做一张主图。

能力动画优先使用：

- 平移；
- 缩放；
- 旋转；
- 抖动；
- 闪白；
- 一张能力叠加图。

不制作骨骼动画和复杂逐帧动画。

### 2.3 UI图标

三选一界面直接复用棋子主图。

如需小图标，可由主图自动缩放，不另做一套。

## 3. 普通棋

### 视觉概念

“揉皱的普通纸团”或“没有特殊标记的基础棋子”。

### 造型要求

- 轮廓最简单；
- 中央使用一个小圆点、叉号或短线；
- 对比度低于特殊棋；
- 不要像任何能力棋。

### 动画

- 下落：整体平移；
- 碰撞：压扁后回弹；
- 被爆炸推动：快速滑动；
- 飞出棋盘：缩小并向外飞走。

## 4. 得分棋

### 视觉概念

“价格标签”“计数器”或“会增长的数字核心”。

### 造型要求

- 中央使用数字、票据、加号或发光圆核；
- 外形较完整、容易反复识别；
- 可以加入层层叠加的小刻度，暗示指数增长；
- 不使用爆炸尖刺。

### 动画

每次受到作用时：

1. 棋子快速放大；
2. 中央数字或核心闪白；
3. 弹出 `+2 / +4 / +8 / +16` 等程序文字；
4. 计数越高，抖动或放大幅度可以略微增加。

## 5. 爆炸棋

### 视觉概念

“放射状爆裂纸花”。

### 造型要求

- 外轮廓带尖刺；
- 中央为爆裂符号；
- 六个方向可带短箭头；
- 与旋风棋区分：爆炸棋是向外放射，旋风棋是环形旋转。

### 动画

1. 快速缩小；
2. 突然放大；
3. 闪白；
4. 六个方向出现向外箭头；
5. 周围棋子依次被推动。

### 资源

## 6. 分裂棋

### 视觉概念

“被撕开的双核纸片”。

### 造型要求

- 中央有明显裂缝；
- 两侧各有一个核心或眼睛；
- 外轮廓可呈双叶形；
- 与交换棋区分：分裂棋强调裂缝，交换棋强调双向箭头。

### 动画

1. 裂缝加深；
2. 原棋子向两侧拉开；
3. 原棋子消失；
4. 两张新纸片飞向两个生成方向；
5. 新棋子落位时轻微压缩回弹。

## 7. 反弹棋

### 视觉概念

“弹簧”“回旋镖”或U形回头箭头。

### 造型要求

- 中央必须有清楚的反向箭头；
- 轮廓可做成弹簧或弧形；
- 强调“原路弹回”，不要做成顺时针弯箭头。

### 动画

1. 被撞后向内压缩；
2. 快速回弹；
3. 撞击者向反方向移动1格；
4. 失败时只播放轻微压缩和叉号。

### 资源

```text
Piece_Bounce_01.png
VFX_Bounce_Arrow.png
```

## 8. 胃袋棋

### 视觉概念

“朝单一方向张开的长嘴”或“移动中的胃袋”。

### 造型要求

- 外形有明显的单向开口；
- 口部朝向可通过程序旋转贴图表现；
- 可以有舌头、牙齿或长条胃囊；
- 必须与吞噬棋区分：胃袋棋是单方向吃，吞噬棋是向周围全部吃。

### 动画

1. 朝移动方向张嘴；
2. 沿直线移动；
3. 每吃一枚棋子，嘴部快速闭合一次；
4. 被吃棋子缩小进入口中；
5. 到墙或边缘时轻微回弹停止。

### 资源


## 9. 吞噬棋

### 视觉概念

“六方向张嘴的黑洞”或“环形牙口”。

### 造型要求

- 中央为深色圆洞；
- 周围六方向有牙齿或吸入箭头；
- 轮廓接近圆形或旋涡状；
- 与胃袋棋区分：没有单一朝向，强调全方向吞噬；
- 自身看起来带一次性、不稳定感。

### 动画

1. 中央黑洞快速放大；
2. 周围棋子向中心缩小吸入；
3. 按顺时针或统一节奏依次消失；
4. 最后吞噬棋自身塌缩消失；
5. 弹出总得分文字。

### 资源

## 10. 转向棋

### 视觉概念

“顺时针弯折60°的路标”。

### 造型要求

- 中央使用明显的顺时针弯箭头；
- 箭头角度应接近六边形的60°转向；
- 不要使用完整圆环，避免与旋风棋混淆；
- 可做成折纸路牌形状。

### 动画

成功时：

1. 转向箭头闪亮；
2. 撞击者沿顺时针60°方向移动1格；
3. 棋子本体轻微顺时针摆动后复位。

失败时：

- 箭头撞出一枚叉号；
- 撞击者不移动。

## 11. 交换棋

### 视觉概念

“两张纸片交换位置”或“双向交叉箭头”。

### 造型要求

- 中央使用两枚方向相反的箭头；
- 可以加入两个不同大小的方块或圆点；
- 强调“互换”，不要表现成分裂或复制；
- 轮廓可左右对称。

### 动画

1. 交换棋与撞击者同时缩小；
2. 两者沿弧线交叉移动；
3. 到达新位置后回弹；
4. 撞击者继续沿原方向移动。

### 资源

```text

VFX_Swap_Arrow.png
```

## 12. 旋风棋

### 视觉概念

“六叶风车”或“环形顺时针旋涡”。

### 造型要求

- 中央为顺时针旋涡；
- 外侧可有六个短弧箭头；
- 强调环形移动；
- 与爆炸棋区分：旋风箭头沿圆周，爆炸箭头向外；
- 与转向棋区分：旋风是完整环，转向棋只有一段60°弯箭头。

### 动画

1. 旋风棋顺时针快速旋转；
2. 周围棋子沿环形轨迹移动一个位置；
3. 墙体保持不动；
4. 空位参与轮换，但只播放棋子运动；
5. 棋子到位后依次触发碰撞表现。

为保持可读性，周围棋子的移动动画应同时开始、同时落位，碰撞特效随后按程序队列依次播放。

## 14. 棋子识别检查

| 棋子 | 必须识别的视觉关键词 |
|---|---|
| 普通棋 | 无能力、简单 |
| 得分棋 | 数字、计数 |
| 爆炸棋 | 向外扩散 |
| 分裂棋 | 裂成两个 |
| 反弹棋 | 原路返回 |
| 胃袋棋 | 单方向吞食 |
| 吞噬棋 | 六方向吞食 |
| 转向棋 | 顺时针转60° |
| 交换棋 | 两者互换 |
| 旋风棋 | 周围环形旋转 |

缩小到实际棋盘尺寸后，中央符号必须仍清楚。

## 15. 制作优先级

### P0：必须完成

- 10枚棋子默认图；
- 爆炸箭头；
- 分裂裂缝；
- 反弹箭头；
- 胃袋咬合；
- 吞噬吸入；
- 转向箭头；
- 交换箭头；
- 旋风环；
- 通用碰撞与阻挡效果。

### P1：有时间再做

- 得分棋不同计数的亮度变化；
- 吞噬棋更明显的塌缩动画；
- 胃袋棋连续咀嚼变化；
- 旋风环形轨迹线；
- 每类棋子的触发高亮图。

### P2：直接可砍

- 多套棋子皮肤；
- 复杂逐帧动画；
- 棋子表情变化；
- 3D光照；
- 高成本粒子；
- 独立卡牌插画。

## 17. 验收标准

1. 10种棋子在实际尺寸下一眼可区分；
2. 胃袋棋与吞噬棋不会混淆；
3. 爆炸棋、转向棋和旋风棋的箭头方向不同；
4. 分裂棋与交换棋的中央符号不同；
5. 所有动画可由一张主图配合程序Tween完成；
6. 特效不会遮挡棋盘格和碰撞目标；
7. 整体保持剪纸、拼贴、粗线和有限色板风格；
8. 资源量符合Game Jam开发周期。
