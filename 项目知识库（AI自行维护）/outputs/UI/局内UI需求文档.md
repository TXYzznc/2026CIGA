# 局内 UI 需求文档

> 依据：`raw/gamejam美术需求文档 (1).docx` 第 4/7/9/10 节 + 需求文档（关卡→轮次→拍击回合结构）。
> 美术风格锚点：`Assets/Art/棋子棋盘/组合示例.png`——温暖手绘水粉/厚涂风（深蓝夜色背景、暖棕木框、笔触明显的画布面、绘本插画质感）。所有 UI 必须像"画在这个手绘场景里的木牌和画板"，与棋盘木框同一材质语言；禁止现代扁平风、剪纸拼贴风、发光科技风。
> 分辨率基准：1920×1080 横屏。全部 PNG 透明底，九宫格可拉伸件需注明。

## 一、局内 HUD（常驻，P0）

### 1.1 布局总览

```
┌─────────────────────────────────────────────┐
│ [关卡轮次 1-2]              [分数面板]        │  ← 顶部
│                                             │
│                                             │
│                 （棋盘区域）                  │
│                                             │
│ [重力箭头]                                   │
│              [剩余次数]      [拍击按钮]       │  ← 底部
└─────────────────────────────────────────────┘
```

- 棋盘居中偏上，HUD 元素全部贴边，不遮挡棋盘旋转范围。
- 验收标准（美术文档第 10 节）：玩家第一眼能答出"哪个按钮能按、还剩几次、重力朝哪"。

### 1.2 元素明细

| 元素 | 内容 | 状态 | 备注 |
|---|---|---|---|
| **拍击按钮** | 画面最重要按钮，大手掌造型（美术文档建议） | ①可点击 ②按下 ③不可点击（结算中置灰） | 屏幕右下，最大的 UI 元素；按下时程序做缩放+震屏 |
| **分数面板** | `当前分数 / 目标分数`，如 `320 / 500` | 常态；得分跳字时程序做数字滚动+弹跳 | 屏幕右上；当前分 ≥ 目标分时数字变为达成色（暖金） |
| **剩余拍击次数** | 数字 + 小手掌图标，如 `×5`；或 7 个小图标逐个熄灭 | 常态 / 最后 1 次警示（微红/摇晃） | 拍击按钮旁边，强关联 |
| **关卡-轮次标签** | `1-2` 格式（第1关第2轮） | 常态 | 屏幕左上，小木牌样式 |
| **重力箭头** | 固定朝下的粗箭头 | 常驻不动（重力永远朝屏幕下方） | 棋盘左侧或下方；手绘粉笔/颜料笔触 |
| **连击/飘分** | `+100`、`COMBO×3` | 程序文字（美术文档明确：优先程序字，不出图） | 只需定一个字体+描边样式 |

| `UI_Smack_Pressed` | 拍击按钮-按下 | 同上，整体下压/变形 |
| `UI_Smack_Disabled` | 拍击按钮-禁用 | 同上，去色/蒙灰 |

## 二、三选一弹窗（P1）

### 2.1 触发与规则（对齐需求文档 13 节）

- 每轮**前 6 次拍击**结算稳定后各弹一次；第 7 次拍击后不弹（直接进轮次结算）。
- 轮次通过后连弹两次（轮间奖励），共用同一界面。
- 弹窗期间棋盘置于底层暗化，禁止旋转/拍击。

### 2.2 界面结构

```
        ┌───────────────────────┐
        │      选择一枚棋子       │  ← 标题条
        │  ┌────┐ ┌────┐ ┌────┐ │
        │  │卡1 │ │卡2 │ │卡3 │ │  ← 三张同底板棋子卡
        │  └────┘ └────┘ └────┘ │
        │        [ 跳过 ]        │
        └───────────────────────┘
```

| 元素 | 状态 | 交互 |
|---|---|---|
| 棋子卡 ×3（同一底板，换棋子图+名称） | ①常态 ②选中高亮（描边/浮起） | 点选→高亮→确认放置（点第二下或自动确认，程序定） |
| 跳过按钮 | 常态/按下 | 不选任何棋子直接关闭 |
| 弹窗底板 | — | 木框画板，出场做程序缩放弹入 |
| 背景遮罩 | — | 半透明深色，纯色即可不出图 |

- 卡面内容：棋子大图标 + 名称（普通棋/得分棋/爆炸棋/分裂棋）。**不写小字说明**（美术文档棋子统一要求：靠轮廓和符号区分）。
- "棋盘已满"时选中后提示丢弃——用程序文字提示，无需出图。

### 2.3 资源清单

| 文件名 | 说明 | 规格 |
|---|---|---|
| `UI_ChoicePanel` | 弹窗大底板 | ~1200×800，可九宫格 |
| `UI_ChoiceCard` | 棋子卡底板（3 张复用同 1 张图） | ~320×420 |
| `UI_ChoiceCard_Selected` | 选中态（可为叠加描边框） | 同上 |
| `UI_Skip_Normal` / `UI_Skip_Pressed` | 跳过按钮两态 | ~300×120 |
| 棋子图标 | 复用 `Piece_*` 棋子图，不另出 | — |

## 三、轮次结算弹窗（P2 但成功/失败判定展示是 P0 信息）

### 3.1 触发与规则

- 每轮第 7 次拍击结算稳定后弹出（每一轮都有，如 1-1、1-2、2-1……）。
- **成功**（当前分 ≥ 目标分）：显示过关、最终分数、目标分数、扣除目标分后的**继承分数**；按钮→ 下一轮（轮间流程）或下一关（本关最后一轮）。
- **失败**（当前分 < 目标分）：显示失败、最终分数、目标分数；按钮 → 重试（回到当前关第 1 轮，全部重置）。

### 3.2 界面结构

| 元素 | 成功版 | 失败版 |
|---|---|---|
| 标题 | "过关！"（暖金/庆祝） | "失败…"（灰暗/耷拉） |
| 关卡轮次 | `1-2` | `1-2` |
| 数据行 | 最终分数 / 目标分数 / 继承分数 | 最终分数 / 目标分数 |
| 主按钮 | 下一轮 / 下一关 | 重试 |

- 成功与失败**共用同一底板**，换标题图和按钮文字（省资源，美术文档第 8 节精神）。
- 标题建议出 2 张手绘字图（"过关！""失败…"），比程序字更有纸艺味；时间不够则程序字。

### 3.3 资源清单

| 文件名 | 说明 | 规格 |
|---|---|---|
| `UI_ResultPanel` | 结算弹窗底板（成功/失败共用） | ~1100×850，可九宫格 |
| `UI_Result_Win` | "过关"手绘标题 | ~600×200 |
| `UI_Result_Lose` | "失败"手绘标题 | ~600×200 |
| `UI_Button_Main_Normal` / `UI_Button_Main_Pressed` | 通用主按钮两态（下一轮/重试共用，程序换字） | ~420×140 |

## 四、通用规范

1. **风格一致性**：所有面板 = 手绘木框画板、木牌与厚涂笔触按钮，与棋盘木框同一材质语言；笔触可见、边缘柔和微不齐，禁止完美几何圆角矩形和硬描边，禁止剪纸/拼贴元素（胶带、图钉、撕纸边）。
2. **配色**：背景深蓝夜色系（#1a2340 左右），UI 用暖棕木色 + 米黄画布色 + 橄榄绿；强调色暖金（得分/成功）、暗红（失败/警示）各一个，不再加色。
3. **字体**：选一款手写感中文字体全局通用；程序飘字同字体加深棕描边。
4. **状态变化优先程序做**（缩放/压扁/闪白/置灰），美术只出必要的独立状态图（拍击按钮 3 态、卡片选中态）。
5. **出图顺序**（对齐美术文档优先级）：
   - P0：拍击按钮 3 态、分数/次数面板、重力箭头、关卡轮次牌
   - P1：三选一全套
   - P2：结算全套、手绘标题字
