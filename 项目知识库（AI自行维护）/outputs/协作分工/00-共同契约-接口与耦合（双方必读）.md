# 共同契约：接口交接表（双方必读）

> 分工：**A = 回合内**（拍击→结算→稳定），**B = 回合外+全局**（状态机、关卡、UI、三选一、配置）。
> 表格字段：**负责程序**（谁实现并维护）- **接口** - **调用方式**（谁在什么时机调）- **功能**。
> 改动任何接口签名，必须当面同步后再改。共享代码放 `Assets/Scripts/Shared/`。

---

## 一、基础数据（双方共用的类型）

| 负责程序 | 接口 | 调用方式 | 功能 |
|---|---|---|---|
| A | `Hex(q, r)` 结构体 + `Hex.Directions[6]` | 双方随处使用 | 六边形轴坐标与六方向定义（D0~D5 顺时针），全项目地基，第一天上午冻结 |
| A | `Hex.Neighbor(int dir)` | 双方随处调用 | 取某方向相邻格坐标 |
| A | `Hex.Distance(Hex other)` | A：分裂最近空格规则 | 六边形格距离 |
| A | `enum PieceType { Normal, Score, Explosion, Split }` | 双方共用 | 棋子类型 |
| A | `enum CellContent { Empty, Piece, Wall, OutOfBoard }` | 双方共用 | 格子内容 |
| A | `class Piece { ID, Type, Position, TriggerCountThisSmack, View }` | 双方共用 | 棋子数据。ID 由 Board 自增分配；View 指向 B 创建的表现物体 |

## 二、棋盘数据模型 Board（唯一真相源，最大耦合点）

| 负责程序 | 接口 | 调用方式 | 功能 |
|---|---|---|---|
| A | `Board.GetContent(Hex)` / `Board.GetPiece(Hex)` | 双方任意时刻（只读） | 查询格子内容 / 取格子上的棋子（无则 null） |
| A | `Board.AllPieces()` | 双方任意时刻（只读） | 全部存活棋子 |
| A | `Board.EmptyCells()` | B：三选一放置时 | 全部合法空格（棋盘内、非墙、无棋子） |
| A | `Board.IsInside(Hex)` | 双方（只读） | 坐标是否在棋盘内 |
| A | `Board.PlaceWall(Hex)` | B：关卡初始化时 | 放置墙体（墙是 CellContent，不是 Piece） |
| A | `Board.PlacePiece(Piece, Hex)` | B：初始生成、三选一放置时 | 放入新棋子（棋子须已带 View） |
| A | `Board.MovePiece(Piece, Hex)` | A：结算中 | 移动棋子 |
| A | `Board.RemovePiece(Piece)` | A：结算中 | 移除棋子 |
| A | `Board.Clear()` | B：重开 / 进入下一关时 | 清空棋盘 |

**读写互斥规则（必须遵守）**：`ResolvingEvents` 状态内只有 A 写 Board；其他所有状态只有 B 写。永不并发。

## 三、核心流程接口

| 负责程序 | 接口 | 调用方式 | 功能 |
|---|---|---|---|
| A | `ExecuteSmack(int boardOrientation, SmackRules rules, Action<SmackResult> onRoundStable)` | B：玩家按拍击、状态切到 ResolvingEvents 后调用一次 | **全项目最重要接口。** A 执行全部重力移动、碰撞、能力连锁的逻辑结算并逐事件播放动画；全部结束后回调 onRoundStable（恰好一次） |
| A | `struct SmackResult { ScoreGained, MaxCombo, EventOverflow }` | B：在回调里消费 | 本次拍击总得分（B 累加进总分）、最高连击（表现用）、是否触发安全上限（B 播"能量过载"提示） |
| A | `SimulateSmack(int boardOrientation) → PreviewResult` | B：每次旋转结束后调一次（不要每帧调） | 只读模拟初始重力移动（不含连锁），返回各棋子落点 + 会碰撞的棋子ID，供旋转预览画虚影/描边。**第一裁剪项，可不实现** |
| B | `int BoardOrientation`（0~5） | B 持有并在旋转时更新；拍击时作为参数传给 A | 棋盘当前朝向。约定 Orientation=0 时屏幕下方=D0。A 永远不直接读 B 的状态，只认参数 |
| B | `struct SmackRules { EventLimit, PieceTriggerLimit, ScorePieceBaseScore }` | B：从配置表打包，随 ExecuteSmack 传入 | A 需要的全部规则参数（500 / 50 / 得分棋基础分），A 不直接读 ScriptableObject |

## 四、表现层接口（A 的动画依赖 B 的资产）

| 负责程序 | 接口 | 调用方式 | 功能 |
|---|---|---|---|
| B | `IPieceViewFactory.CreateView(PieceType, Hex)` | A：结算中 Spawn（分裂生成）时；B：初始生成、三选一时 | 实例化对应棋子 prefab 并摆到位，返回 PieceView。A 全程不碰 prefab 资产 |
| B | `IPieceViewFactory.DestroyView(PieceView)` | A：结算中 Remove 时 | 销毁棋子表现物体 |
| B | `BoardView.HexToWorld(Hex) → Vector3` | A：播放移动动画时 | 逻辑坐标 → 世界坐标（含棋盘当前旋转角度）。A 不自己算世界坐标 |
| B | `PieceView.MoveTo(Vector3) → float` | A：播放器逐事件调用 | 移动补间，返回时长（秒），A 用返回时长串时序 |
| B | `PieceView.PlayHitShake() → float` | A：碰撞事件播放时 | 被撞震动 |
| B | `PieceView.PlayAbilityFX() → float` | A：能力触发事件播放时 | 能力特效（按棋子类型区分），可顺带做飘分 |
| B | `PieceView.PlaySpawn() → float` / `PlayRemove() → float` | A：生成 / 移除事件播放时 | 生成、移除/推出棋盘的表现 |

**第 1 小时 B 先交全空实现（每个动画返回 0.1f），A 立刻可用，真动画 24h 联调点替换。**

## 五、分数与状态归属（防止两边重复实现）

| 负责程序 | 数据/职责 | 交接方式 |
|---|---|---|
| A | 连击数、单次拍击得分、单棋子触发计数、安全上限 | 通过 `SmackResult.ScoreGained` 一次性交给 B |
| B | 累计分数、目标分数判定（差值>0 过关，等于失败）、剩余拍击次数 | 不传给 A，A 不需要 |
| B | 全部随机数（初始生成、三选一抽取与放置） | A 的结算**纯确定性**，内部禁用 Random |
| B | 状态机、输入锁、场景、全部 prefab | A 不打开场景、不改 prefab 资产 |

## 六、时间线与裁剪

| 时间点 | 里程碑 |
|---|---|
| 0~1h | 一起建好 `Shared/` 全部签名（空实现也算），双方各自可编译 |
| ~12h 联调① | 真 ExecuteSmack 接入（普通棋+得分棋），跑通"旋转→拍击→得分→三选一→再拍"闭环 |
| ~24h 联调② | 爆炸棋接入；真动画替换空实现 |
| ~36h | 分裂棋（或裁剪）、旋转预览、关卡数值 |
| 36~48h | 只修 bug 和打磨，不加新功能 |

裁剪顺序（先砍上面的）：① `SimulateSmack` 旋转预览 → ② 分裂棋 → ③ 三选一权重/保底（退化纯随机） → ④ 完整 COMBO 界面（退化飘字）。
**不可裁剪**：事件 FIFO、逐事件串行播放动画（玩法可读性底线，策划案 17.2）。
